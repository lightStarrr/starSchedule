# 壁纸工作室与参数壁纸验证

## 实现

- 壁纸入口保留照片选择，工作室采用一张大表情卡片、下方纯色与无背景两张小卡片。
- 表情卡片由系统动态色种子和现有布局、Canvas 绘制器生成；点入原有编辑器可改表情、图案、尺寸和配色。
- 编辑完成只向课表预览传绘制参数。表情壁纸、纯色与照片都需要点「应用」才写入目标课表。
- 纯色预览提供系统配色及黑白色；「无」回到创建课表时的动态主题背景。
- 新表情壁纸保存表情序列、图案、尺寸档位、颜色、随机种子和可选模糊半径，课表按实际画布尺寸重新计算并绘制。最近壁纸也保存参数，不创建整屏 PNG。
- 只缓存绘制器已有的字形纹理，不缓存整屏图片。旋转与窗口调整按实际画布排布；课表设置的壁纸缩略图先按完整窗口计算布局，再缩小裁切，避免方形槽位改变堆叠图案的行列数。
- 沿用原课表壁纸偏好键并扩展值格式；Room schema/version、照片格式、Provider、Widget 和提醒契约未变。
- 已经保存的旧表情 PNG 继续按照片显示，无法从像素恢复编辑参数；重新通过表情编辑器应用后使用参数绘制。
